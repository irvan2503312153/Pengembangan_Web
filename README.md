# Pengembangan_Web
## REST API CURD MAHASISWA (Express.js)

**Daftar Endpoint yang Tersedia:**

GET `/mahasiswa` - Menampilkan semua data mahasiswa   
GET `/mahasiswa`/:id - Menampilkan data mahasiswa berdasarkan ID   
POST `/mahasiswa` - Menambahkan data mahasiswa baru   
PUT `/mahasiswa`/:id - Mengubah data mahasiswa  
DELETE`/mahasiswa`/:id - Menghapus data mahasiswa   

**Cara Menjalankan Program:**

1. Clone repository ini atau download ZIP.
2. Jalankan npm install di terminal.
3. Jalankan server dengan perintah node httpsexpress.js.
